# 제주 여행 지도

제주 섬 전체를 담은 3D 지도에 여행 일정을 넣고, 실제 도로를 따라 동선을 미리 보는 웹앱입니다.
휴대폰에서 홈 화면에 추가하면 인터넷 없이도 열립니다. 일정은 각자 기기(브라우저)에만 저장되고 이 저장소나 사이트로 올라오지 않습니다.
